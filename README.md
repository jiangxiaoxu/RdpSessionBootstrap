# RDP Session Bootstrap

Windows 开机登录辅助工具. 开机后使用安装账号连接本机 RDP (`127.0.0.1:3389`), 确认会话 Active 后等待 5 秒, 关闭本次 RDP 客户端并保留用户会话, 让需要登录后运行的程序继续工作. 如果目标账号已有会话, 则跳过登录.

**[下载最新版](https://github.com/jiangxiaoxu/RdpSessionBootstrap/releases/latest)** | **[下载 0.1.0 单文件安装器](https://github.com/jiangxiaoxu/RdpSessionBootstrap/releases/download/v0.1.0/RdpSessionBootstrap-Setup-0.1.0.exe)**

仓库目前为 private, 下载需要具有仓库访问权限的 GitHub 账号.

## 安装要求

- Windows x64, 已启用远程桌面服务, 本机 RDP 端口为 3389.
- 安装账号具有 RDP 登录权限和管理员权限. UAC 提权必须保持同一账号, 不支持输入另一个管理员账号的凭据.
- 首次安装需要 Windows 账号密码, 不能使用 Windows Hello PIN.

安装包包含 .NET runtime 和所需客户端, 无需额外安装 .NET. 工具不会代为启用 Windows 远程桌面或修改其登录权限.

## 安装, 升级与卸载

1. 下载并双击 `RdpSessionBootstrap-Setup-0.1.0.exe`, 同意 UAC 提权.
2. 首次安装输入当前 Windows 账号密码, 点击"安装".
3. 成功后点击"完成"关闭窗口. 服务设为自动启动, **下次开机生效**, 安装时不会立即发起 RDP 登录或重启.

已有安装时, 新版本显示"升级", 同版本显示"修复", 较旧安装包不能覆盖更高版本. 升级和修复必须使用原安装账号, 保留配置, 加密凭据和日志, 无需重新输入密码, 同样在下次开机生效.

卸载可通过 Windows 设置的"已安装的应用", 或再次运行安装器并点击"卸载". 卸载会停止本服务及其客户端, 删除安装文件, 配置, 凭据和日志, 不注销已有用户会话. 下载的安装包会保留.

账号密码或本机 RDP 证书变更后, 需要卸载再安装以更新保存的信息; 升级和修复不会更新凭据配置.

## 运行行为与日志

每次服务启动最多发起一次 RDP 登录, 不自动重试. 五秒等待期间, 如果本地客户端被其他 RDP 连接打断并退出, 服务会结束等待, 不重连. 清理只针对本次启动的客户端进程, 避免误断开接管同一会话的新连接. 一次运行结束后服务显示 `Stopped` 属于正常状态.

在安装器中点击"打开日志文件夹"即可查看日志, 安装或升级完成后仍可使用该按钮. 目录为:

```text
C:\ProgramData\RdpSessionBootstrap\logs
```

每次服务启动创建独立的 `service-<UTC时间>-<唯一标识>.log`, 手动启动服务也会创建新文件. 服务启动时清理最后写入时间超过 7 天的本程序日志, 包括旧的 `service.log`. 过期文件会保留到下一次服务启动时再清理. 日志不记录密码或客户端认证输出.

## 文件与权限

安装位置固定为 `C:\ProgramData\RdpSessionBootstrap`. SYSTEM 和 Administrators 对安装目录有完全控制权. 安装账号在普通权限下的访问范围如下, 其他普通账号不授予访问权:

| 位置 | 内容 | 安装账号的普通权限 |
| --- | --- | --- |
| 安装根目录 | 下列子目录 | 通过已知路径访问子目录和读取属性, 不能列举内容 |
| `app/` | 服务, Setup 和 .NET 依赖 | 读取和执行, 不能修改或删除 |
| `client/` | RDP 客户端和第三方许可证 | 不可读取 |
| `private/` | 账号配置和 DPAPI 加密凭据 | 不可读取 |
| `logs/` | 每次运行的日志 | 只读 |

服务以 LocalSystem 运行. 密码使用机器范围 DPAPI 加密保存, 不写入命令行或日志. 升级和修复会迁移旧安装的目录权限.

安装解压目录和卸载临时副本位于系统公共数据目录 (通常为 `C:\ProgramData`) 下的 `RdpSessionBootstrap-Setup-<随机标识>` 和 `RdpSessionBootstrap-Uninstall-<随机标识>`, 仅 SYSTEM 和 Administrators 可访问. 安装临时目录在界面关闭后删除; 卸载临时副本在下次开机清理.
